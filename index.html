Sobre mí

Soy desarrollador Full Stack con experiencia en proyectos web de diversa escala: desde páginas institucionales hasta aplicaciones con arquitecturas modernas y API REST. Me especializo en backend con PHP (Laravel) y Python (Django), así como en frontend con HTML, CSS y Bootstrap.

Poseo experiencia en control de versiones con Git, bases de datos relacionales (MySQL, PostgreSQL) y en el ciclo completo de desarrollo: diseño, implementación, pruebas y despliegue.
